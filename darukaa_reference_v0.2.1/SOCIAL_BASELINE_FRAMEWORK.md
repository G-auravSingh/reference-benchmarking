# Social-Dependency & Feasibility Baseline — Framework (placeholder)

Structure now; data collection next cycle. Addresses reviewer comments J1–J4: zoning /
fuelwood / grazing / access / no-conversion recommendations were made with **no social,
tenure, or feasibility baseline**. This module is REQUIRED wherever restoration
recommendations interact with people and land use. It is not yet populated — this file
defines what must be collected and how it enters the framework (as C4 "human interface",
never blended into the ecological condition score).

## Required components
1. **Tenure & ownership** — statutory + customary rights; who holds/uses each parcel.
2. **Resource dependence** — grazing, fuelwood, NTFP, water, access routes; seasonal use.
3. **Livelihood dependence** — reliance on the landscape; wildlife costs/benefits.
4. **Existing land-use objectives** — current plantation/farming objectives that any
   recommendation must be compatible with.
5. **Feasibility & safeguards** — can a recommendation actually be implemented; consent;
   FPIC where applicable; monitoring indicators; responsible agency.

## How it enters the framework
- Construct **C4 · pressures & human interface**, subdimension `dependencies`.
- Evidence tier: **baseline** only when field-collected; otherwise `pending input`.
- Feeds the **condition × pressure matrix** and the intervention-feasibility narrative —
  it does **not** enter the ecological condition score (no double counting).

## TNFD/LEAP link
This is the "dependencies" half of TNFD that a score alone cannot cover — required for an
honest LEAP Assess/Prepare. See TNFD_LEAP_CROSSWALK.md.

## Method (next cycle)
Participatory mapping + household/user survey co-developed with communities and agencies;
outputs documented with provenance and consent; recommendations co-developed, not imposed.
