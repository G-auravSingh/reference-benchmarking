3. Design principles

  • Segment/cluster before logistics. The ecological unit (EMU) is decided on ecological grounds first, then fitted to devices, days, and access.
  • EMU membership stays real and complete, even when scattered. A farm parcel that's geographically far from most of its EMU is never split into a separate unit just for tidiness — it keeps contributing to that EMU's ecological metrics. It's simply excluded from device-position eligibility if it's too isolated for a field visit to be practical (see §6).
  • Device coverage is a hard guarantee. An EMU this pipeline delineates and cannot cover with available devices is treated as an internal error to fix, never a client-facing "uncovered EMU" finding.
  • Distribution shown alongside the worst-case flag, never the flag alone — a single declining tile inside an otherwise-healthy EMU should never read as "no improvement happening" project-wide.

4. Site selection methodology — this run

Method: Gower-distance ecological clustering with a spatial k-nearest-neighbour connectivity constraint, so ecologically-similar candidates can only group together if they're geographically reachable through a chain of nearby candidates.

K bounds this run: k_min=2, k_max=16 (logistics ceiling 16, replication ceiling 631, achievable cycles 4).

10. Declared caveats

  • Slope_deg: only 82.8% coverage across candidates
  • JRC_Water: only 0.1% coverage across candidates
  • 127 candidate(s) in this project had BuiltUp_Pct above the threshold but were kept anyway because their NDVI showed real vegetation — the land-cover classifier appears to be misclassifying part of this site as built-up (a known failure mode on managed/plantation landscapes: a young plantation's bare-soil-between-rows pattern showing BuiltUp_Pct near 100 with NDVI 0.24-0.35, physically inconsistent with a real built surface). Worth a visual/field check on this specific classifier behaviour.
  • 207 candidate(s) across 6 EMU(s) are real members (kept for metrics) but excluded from device-position eligibility as spatial outliers — too far from the rest of their EMU for a field visit to be practical: {'FCF_GV_EMU_Ganjam_1': 60, 'FCF_GV_EMU_Kandhmal_2': 33, 'FCF_GV_EMU_Kandhmal_1': 39, 'FCF_GV_EMU_Gajapati_1': 29, 'FCF_GV_EMU_Kalahandi_1': 30, 'FCF_GV_EMU_Kalahandi_2': 16}. This is a deliberate design choice: a severe outlier doesn't need its own EMU, it just shouldn't be a device candidate.
  • 5 panels needed; fits within 6 weeks (+1 week extension) but NOT the base 5 weeks. Using the extension — this is the last-resort case per policy (devices cannot be added), flagged explicitly rather than applied silently. Confirm before mobilising.
  • BuiltUp_Pct: identical value (0.0) across every EMU — zero variance across a whole site is almost always a computation defect, not real ecological uniformity. Treat this covariate as unreliable until investigated at the GEE script level.

  • Hansen, M. C., et al. (2013, with ongoing annual updates). High-resolution global maps of 21st-century forest cover change. Science, 342(6160), 850–853. — global forest-loss reference dataset.
