3. Design principles

  • Segment/cluster before logistics. The ecological unit (EMU) is decided on ecological grounds first, then fitted to devices, days, and access.
  • Spatial contiguity is a structural guarantee for segmentation-derived EMUs — verified by a hard runtime check, not assumed.
  • Device coverage is a hard guarantee. An EMU this pipeline delineates and cannot cover with available devices is treated as an internal error to fix, never a client-facing "uncovered EMU" finding.
  • Distribution shown alongside the worst-case flag, never the flag alone — a single declining tile inside an otherwise-healthy EMU should never read as "no improvement happening" project-wide.

4. Site selection methodology — this run

Method: GEE SNIC image segmentation over the tessellated grid, reconciled with client-declared ecological anchors.

Residual unclassified area: 12.976 ha (real leftover land not covered by any anchor, exclusion, or EMU — reported explicitly, not dropped).

Within-EMU position ranking: CRITIC-weighted typicality (feature tier: full_with_satellite_covariates). Top-weighted covariates this run: LST_C (0.110), gHM (0.103), NightLights (0.088), DistWater_m (0.087), NatCoverPct_2km (0.085), EdgeDensity_500m (0.078), NatCoverPct_500m (0.075), TreeCover_Pct (0.074).

10. Declared caveats

  • 102 of 1294 candidate cells did not fall within any real eco-zone polygon (likely the 4.08ha unaccounted-for gap area found during preprocessing) — these cells have eco_zone=None and will not be assigned to any EMU.
  • gHM: only 98.5% coverage across candidates
  • JRC_Water: only 2.7% coverage across candidates
  • 12.976 ha (10.2% of AOI) is not covered by any anchor, exclusion, or EMU — this is real leftover land, not dropped silently; needs either the candidate-grid fix above or manual review before reporting.
  • 1 candidate(s) across 1 EMU(s) are real members (kept for metrics) but excluded from device-position eligibility as spatial outliers — too far from the rest of their EMU for a field visit to be practical: {'EMU_Grass_land': 1}. This is a deliberate design choice: a severe outlier doesn't need its own EMU, it just shouldn't be a device candidate.
  • 3 EMU(s) had real capacity below what a full season's rotation needs at the standard 100m spacing floor (fewer real positions than season_length_weeks, meaning some positions would repeat within a single season) — relaxed for these EMUs specifically: {'EMU_Trail_plots': 66.42441103205844, 'EMU_Wetland_forest': 50.0, 'EMU_Wildlife': 50.0}. Real trade-off (some acoustic overlap risk between devices) accepted in exchange for genuine spatial/temporal variety instead of an unnecessarily repeated spot. Not applied to any other EMU in this project.
  • Camera trap (1 device(s)) cannot visit every one of 9 real zones at least once per 8-week season — ['Wetland forest'] (smallest by real area) excluded from camera trap rotation for the whole programme, every season, by deliberate design. Audiomoth still covers it every week via its own permanently-assigned device; only camera trap coverage is affected.
  • ['NDVI_raw', 'TreeCover_Pct', 'BuiltUp_Pct', 'Elev_m', 'ElevStd_m', 'TRI_m', 'Slope_deg', 'gHM', 'DistWater_m', 'LST_C', 'NightLights'] have ZERO project-level coverage despite other covariates having real data — found while validating against Soulforest's real GEE output: this project's grid cell size (25m, 0.0625 ha) sits BELOW small_tile_area_ha_floor (0.25 ha), so every single cell is excluded from these parcel-intrinsic metrics as low-confidence — not a bug, the floor is doing exactly what it's configured to do, but it silently zeroes out this whole indicator family for any contiguous-archetype project at this resolution. Needs a decision: raise the grid cell size, lower the floor for contiguous archetypes specifically, or accept these indicators being unavailable at this resolution.
  • SCIENTIFIC DEFENSIBILITY: 1 EMU pair(s) show near-identical covariate profiles (normalized distance < 0.08): [('EMU_Grass_land', 'EMU_Savana_ecosystem', 0.028)]. Image segmentation found a real spectral discontinuity between them, but their aggregate covariate values barely differ — plausibly SNIC oversegmentation rather than a genuine ecological distinction. Field reconnaissance should confirm or correct this before treating them as separately meaningful strata in any client-facing ecological interpretation.
